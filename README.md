# Cognifyz Data Science Internship Project

## Overview
This repository contains the tasks completed as part of the Cognifyz Technologies Data Science Internship Program.

The project includes:
- Data Exploration and Preprocessing
- Price Range Analysis
- Data Visualization

## Tools and Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Tasks Completed

### Level 1 - Task 1
- Dataset exploration
- Missing value analysis
- Data type checking
- Aggregate rating distribution analysis

### Level 2 - Task 2
- Most common price range analysis
- Average rating by price range
- Rating color analysis
- Visualization of price ranges

### Level 3 - Task 3
- Distribution visualization using histogram
- Top city rating comparison
- Votes vs Aggregate Rating analysis

## Conclusion
This project helped in understanding data preprocessing, analysis, and visualization techniques using real-world restaurant data.
